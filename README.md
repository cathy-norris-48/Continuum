## 📖 About

Continuum is a productivity workspace built for Windows by a small independent software team. It combines a fast note editor, a lightweight task board and a searchable reference library into a single window, so you do not need to juggle three or four separate tools during the day. The current build focuses on snappier startup, better full text search across notebooks and a cleaner side panel layout. Everything you create is stored in a local folder you choose, which makes backup and migration straightforward.

If you came looking for a Continuum download for Windows 10 or 11, this page lists the current system requirements, install steps and common troubleshooting fixes.

**Good for:** students · writers · developers · project managers · researchers · small teams · anyone replacing scattered notes

## 🛠️ Troubleshooting

| Problem | Solution |
|---|---|
| Setup file blocked by SmartScreen | Click **More info**, then **Run anyway**. |
| Installer closes right after opening | Restart Windows and run the setup file again from your Downloads folder. |
| App opens but the window is blank | Update your graphics driver, then relaunch Continuum. |
| Search returns no results | Make sure the notebook folder still exists and reindex from Settings. |
| Notes not syncing to your backup folder | Check the folder path in Settings and confirm it is writable. |
| High memory use with large notebooks | Close unused tabs and lower the preview history limit in Settings. |
| Shortcut conflicts with another app | Rebind the shortcut in Settings, Keyboard section. |
